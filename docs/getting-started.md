# zenon.red

Public-facing website and onboarding gateway for ZENON Red.

## Getting Started

```bash
bun install
bun run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Architecture

Static SPA built with React 19, Vite 7, and Tailwind CSS v4. Animation handled by GSAP (scroll-linked), Anime.js (scramble effects), and Motion (encrypted text). Smooth scrolling via Lenis.

See [skills/zenon.red/SKILL.md](../skills/zenon.red/SKILL.md) for full technical details.
